\section*{Compute environment}

\autoref{tab:compute} is the machine of record for every number in this thesis. The hardware block
is transcribed from \texttt{sinfo}, \texttt{scontrol show node} and \texttt{lscpu} run on the cluster
on 2026-09-09, cross-checked against the provenance header (\texttt{NODE}, \texttt{GPU INFO},
\texttt{GIT REV}) that every batch job in this project writes to its own log. The software block is
transcribed from the environment-verification job that certified the cluster installation, and from
the pinned dependency list.

Two qualifications belong with the table. The software block is a snapshot taken when the
environment was certified at the start of the project; no version change is recorded in any
subsequent job log, but the environment was not frozen, so the defensible claim is that these
versions were verified at the outset rather than that each one produced every reported number.
And the accelerator, though the GPU is held exclusively, sits in a node whose CPU and memory are
shared, which is why \autoref{sec:setup:protocol} declines to read the timing figures as a hardware
benchmark.

Reproducing a run requires the batch scripts as much as the code: the scheduling parameters, the
GPU pinning and the headless-rendering configuration all live in the job scripts, and each job
records the git revision it ran at in its own log header.

\section*{Names as they appear in the released artefacts}

This thesis names methods by their mechanism and never by the tokens that identify them in
configuration files, checkpoint paths and evaluation logs. That is deliberate --- a name that asserts
something the code does not do should not be repeated --- but it leaves a reader of the released
artefacts unable to match a row of \autoref{ch:results} to a run. \autoref{tab:names} is the map.

\begin{table}[htpb]
  \caption[Thesis names and released artefact tokens]{Thesis name against the token a reader will
  meet in the released configuration files, checkpoint directories and evaluation logs. The tokens
  are deliberately \emph{not} renamed in the artefacts: renaming them would break every existing
  cross-reference in the project's own run ledger.}
  \label{tab:names}
  \centering
  \begin{tabular}{ll}
    \toprule
    Name used in this thesis & Token in the artefacts \\
    \midrule
    \multicolumn{2}{l}{\emph{generative engines}}\\
    the diffusion engine / the baseline & \texttt{GaussianDiffusion}, \texttt{ddpm}, \texttt{diffusion} \\
    flow matching                       & \texttt{FlowMatchingODE}, \texttt{fm}, \texttt{flow\_matcher\_v3} \\
    MeanFlow                            & \texttt{MeanFlowODE}, \texttt{mf} \\
    the bootstrapped target             & \texttt{AlphaFlowODE}, \texttt{af}; floor as \texttt{ae0.2} / \texttt{ae0.05} \\
    \midrule
    \multicolumn{2}{l}{\emph{constraint arms}}\\
    unguided (no projection)            & the \texttt{diffuser} variant row \\

    in-ODE endpoint projection          & \texttt{hardflow\_sls-*}, \texttt{hardflow\_new-*} \\

    \midrule

    random                              & the \texttt{-r} suffix \\

    \midrule

    activation threshold $\eta$         & \texttt{A}, \texttt{activation\_threshold} \\
    genuine steps                       & \texttt{n\_genuine} \\
    corrected scene geometry            & \texttt{u7hg}, ``honest geometry'' \\
    constraint-family ablations         & \texttt{geo\_free}, \texttt{bounds\_free}, \texttt{model\_free} \\
    \bottomrule
  \end{tabular}
\end{table}

Two tokens are traps and are called out rather than merely translated. The bare word
\texttt{diffuser} means three different things in this project's artefacts --- the ancestor codebase,
the published method it is named after, and this work's own no-projection variant row --- and is
never used unqualified in this thesis. And the visual conditioning flag whose value is spelled
\texttt{filmv1} does \emph{not} select feature-wise linear modulation: it concatenates the visual
latent with the time embedding, which yields an additive per-channel bias and no scale term. Every
reported visual number comes from that arm, and \autoref{sec:method:backbone} describes what it
actually computes.
