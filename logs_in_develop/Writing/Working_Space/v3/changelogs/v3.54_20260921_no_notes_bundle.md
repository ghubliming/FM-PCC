# v3.54 — 2026-09-21 · a third note level for the bundle: `--no-notes`

Tooling only. **No thesis text, table, figure or number changed** — `chapters/`, `parts/`,
`figures/` and `bibliography_v3.bib` are untouched by this pass. Nothing was compiled: there is no
TeX toolchain in this container.

---

## Why

The author asked whether the violet `\guard` text disappears in the clean review copy. It does not:
`--clean-notes` sets `\submissiontrue`, which the inherited preamble wires to `\srcnote` **and to
nothing else**, because `\srcnote` is the only drafting macro v2 owns. `\dataref` and `\guard` are
v3's own and had no switch at all. The author asked for one.

## What was added

`bundle/make_bundle.py` gained **`--no-notes`**. There are now three note levels, and the module
docstring states them:

| build | `\srcnote` | `\dataref` | `\guard` | `\hole`, `\provisional` |
| :-- | :-- | :-- | :-- | :-- |
| default | visible | visible | visible | visible |
| `--clean-notes` | hidden | visible | visible | visible |
| **`--no-notes`** | hidden | **hidden** | **hidden** | visible |

Mechanically it injects a second shim before `\begin{document}` — `\submissiontrue` plus
`\renewcommand{\dataref}[1]{}` and `\renewcommand{\guard}[1]{}` — beside the existing
`CLEAN_NOTES_SWITCH`. The file suffix is `_nonotes`, so the three variants never collide in
`output/` or in `BUNDLE_LOG.md`.

## The two things it deliberately does not do

**`\hole` and `\provisional` are never hidden.** They mark work that is missing. A build that hides
them lies about how finished the draft is, and `\hole` already emits a LaTeX warning under
`\submissiontrue` by design.

**A hidden `\guard` is still a limit of the result.** `\srcnote` and `\dataref` are provenance —
internal, and they never ship. A guard is a **caveat**, and the eighteen in the draft are a mix:
some are internal (*"the four panels were rendered at a different dashboard size and are cropped"*),
others state a real limit of a real claim (*"one training seed and one geometry, so the counts
beside the panels are not the rates of Table 6.4"*). Hiding the second kind makes the PDF overstate
the work. So `--no-notes` **reports what it hid** and says what that costs:

```
  review notes: none (\srcnote, \dataref and \guard hidden)
  HIDDEN: 18 \guard caveat(s) and 38 \dataref pointer(s). A hidden guard is still a limit of the result --
          this build reads tidier than the evidence is. Use --clean-notes for anything judged on its claims.
```

The counts come from `count_macro()`, which strips comments first — the preamble documents each
macro in a comment that spells the call, and counting those overstated every total by one. They now
agree with `tools/check.py` exactly (guard 18, dataref 38).

> **Left open, not acted on:** the real fix is to split `\guard` into the caveat that ships and the
> internal note that does not, so that no switch has to choose between them. That is a pass over all
> eighteen uses and belongs with the pass that drives the drafting macros to zero.

rather than removed, because that log is append-only history.
