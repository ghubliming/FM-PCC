**`make_figs.py`**
- Writes to `figures/<group>/`.
- Its manifest lists generated, vendored and other-present figures, plus the planned, excluded and corpora tables.
- It fails if a figure name exists in two groups.

**`export_to_draft.py`** — new; the copy step from the store into a draft:
- reads the draft's master `.tex`, `parts/` and `chapters/`, ignoring comments;
- copies every format present in the store (SVG, and PDF once converted) into `<draft>/figures/`;
- skips identical files;
- `--prune` removes figures the draft no longer uses; `--dry-run` shows what would happen;
- writes `EXPORTED.md` with group, formats, SHA-256 and the using file and line;
- a missing figure makes it exit 1; a planned one is reported.

It was tested on a scratch copy of v3, and each case behaved as intended:
- a deleted figure was copied back;
- a planned name was reported as planned;
- an unknown name was reported as missing, with exit 1;
- a commented-out reference was ignored.

Run against v2 it finds no figures, as expected.

**v3 after export**

- The six other figures remain in the store only.
- The old `MANIFEST.md` from the retired pipeline was removed.
