than inside it). Reasons: the version scheme is v5.N, so the folder is named like the drafts it replaces; its `CHANGELOG.md`

the Orchestra tool read a draft's revision from `<folder>/CHANGELOG.md`, so v5 fits the existing machinery; the Orchestra
folder stays what it was — the job log and the runbook — while the thesis text lives in a draft folder.
